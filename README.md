# Make the Judge Laugh in One Line

A single original one-liner for the make.fun bounty: a passenger asks the flight attendant for a surprise meal choice and gets an answer no menu ever offered. The program writes exactly that line to `/output/entry.txt`, nothing more.

## Run it

```sh
node main.ts
```
